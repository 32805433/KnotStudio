# Example pictures

These eleven example pictures cover SnapPy diagrams, blackboard photographs,
and iPad drawings. Save a picture from the links below, then choose **Open…** in
Knot Studio to load it. If you have downloaded the source archive, the pictures
are in its `examples` folder.

Start with a SnapPy picture, then try the labels, colors, and twist boxes in the
hand-drawn examples.

| Picture | What it shows |
| --- | --- |
| [SnapPy trefoil](../examples/snappy/trefoil.png) | Three crossings |
| [SnapPy figure-eight](../examples/snappy/figure-eight.png) | Four crossings |
| [SnapPy three-component link](../examples/snappy/borromean-link.png) | Color, six crossings, three components |
| [Blackboard labeled diagram](../examples/blackboard/labeled-figure-eight.png) | Chalk texture, handwritten label |
| [Blackboard colored chain](../examples/blackboard/colored-chain.png) | Colored chalk, orientation arrows |
| [Blackboard Hopf link](../examples/blackboard/hopf.png) | Chalk texture, broad crossing gap |
| [iPad negative twist box](../examples/ipad/boxed-parallel.png) | −1 twist box on three strands |
| [iPad parallel omissions](../examples/ipad/parallel-omissions.png) | −2 twist box, gaps across strand bundles |
| [iPad labeled and oriented box](../examples/ipad/labeled-oriented-box.png) | +1 twist box, orientation arrows; delete the marked blue 0 label |
| [iPad labeled knot](../examples/ipad/labeled-knot.png) | Small handwritten label |
| [iPad dense twists](../examples/ipad/dense-twists.png) | Repeated close crossings |

The [HTML gallery](../examples/gallery.html) shows all the pictures together
when opened locally in a web browser. On GitHub, that link shows the HTML source;
use the picture links in the table above to view individual images.
