# Changelog

## 0.1.0

First version of Knot Studio for Mac.

- Recognize knot and link diagrams from screenshots, iPad drawings, and
  photographs of whiteboards and blackboards.
- Review and delete labels before recognition.
- Draw and erase strands, change crossings, and reverse component orientations.
- Move strands, perform Reidemeister moves, and simplify curls and bigons.
- Smooth a selected region or the whole diagram.
- Optional smooth curves for display and LaTeX export.
- Recognize and edit numbered twist boxes. This is currently experimental.
- Save editable diagrams and export images, PD code, and LaTeX drawings.
- Includes example pictures and an offline user guide.
