# Example image credits

The eleven pictures in `examples/` are included with the project owner's
permission.

- **Blackboard and iPad examples:** photographs and drawings supplied by the
  project owner.
- **SnapPy examples:** three diagrams generated locally using SnapPy,
  Spherogram, and PLink, with Matplotlib rendering. Credit to Marc Culler,
  Nathan M. Dunfield, Matthias Goerner, and Jeffrey R. Weeks, together with
  the PLink and Spherogram contributors. See
  [SnapPy's credits](https://snappy.computop.org/credits.html).

The software's GPL license does not cover these example images. For reuse
outside this release, please contact the project owner.
