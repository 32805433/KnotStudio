# Knot Studio demo

[Watch the demo](KnotStudio-demo.mp4), a captioned walkthrough with no audio.
This demonstration recreates the interface using actual program results;
timings have been shortened. It is **not a live screen recording**.

The opening shows automatic recognition of a blackboard photograph, an iPad
sketch, and a labeled research-paper figure. It then follows one continuous
figure-eight session: drawing by hand, Reidemeister II, III and I, successive
simplifications, smoothing a selected region and the whole diagram, then
exporting PD and LaTeX/TikZ code. All editing steps use the same diagram.

- [Chapter list](KnotStudio-demo-chapters.md): start times for each section.
- [Captions](KnotStudio-demo.srt): a separate caption file.
- [Preview picture](KnotStudio-demo-poster.jpg): a still from the demonstration.

## How the demo was made

Recognition, drawing, editing, smoothing, and exports use Knot Studio's actual
results. The interface and pointer are recreated, and pauses for computation
are shortened. Simplifications appear immediately after a click. Each step
continues from the preceding result, and the final exports use that same diagram.

## Picture credits

The opening uses the project owner's
[colored blackboard photograph](../examples/blackboard/colored-chain.png), an
iPad sketch, and a cropped diagram from page 12 of
[The Delunification Process and Minimal Diagrams](https://arxiv.org/abs/1406.2378)
by Slavik Jablan, Louis H. Kauffman, and Pedro Lopes. The iPad sketch and paper
crop are not separate example files in this release. The blackboard's actual
**Needs review** status is retained on screen.
